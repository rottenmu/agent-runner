登录态老是丢，刷新页面就退出了。帮我看下哪里写错了。

定位到了：写入与读取落在两个不同的 Storage，且键名不一致。登录成功时写的是 localStorage.session_token，而路由守卫读的是 sessionStorage.token —— 同源的两个存储互不可见，刷新后读到的永远是空值。

改动只有两行：把读取端也指向 localStorage，并把键名收敛到一个常量。

src/api/auth.js 
// 键名收敛到一处，写读共用
const TOKEN_KEY = 'dsh.session_token'

export function saveToken(token) {
  localStorage.setItem(TOKEN_KEY, token)   // 原为 localStorage.session_token
}

export function readToken() {
  return localStorage.getItem(TOKEN_KEY)   // 原为 sessionStorage.token
}

顺带把守卫里的取用点也换成 readToken()，避免第三次出现字面键名。
