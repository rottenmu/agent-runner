# 星炬 AI 智能体基础框架 — 产品介绍

## 解决什么问题

企业构建 AI 应用时面临三大技术挑战：**每个业务模块都要重复对接大模型**（同样的事情做多次）、**技能能力无法跨模块共享**（WMS 的库存查询和采购的订单查询各写各的 AI 调用）、**多个外部渠道（飞书/企微/网页）接入 AI 时架构不统一**（每加一个渠道都要重新设计）。

星炬 AI 智能体基础框架（ai-agent-spring-boot-starter）是平台的 AI 能力底座，以 Spring Boot Starter 形式提供"一次接入、多模块复用、多渠道输出"的标准化 AI 基础设施。

## 核心能力

- **大模型调用**：内置 OpenAI 兼容格式的模型客户端，支持百炼 DashScope 和自定义模型，只需配置 API Key 即可开始对话
- **技能注册体系**：业务模块声明 `AiSkill` Bean 即自动注册，支持 Spring Bean 技能和远程 API 技能，注册中心负责收集和调度
- **多智能体路由**：按租户、渠道、用户维度自动匹配最佳智能体，支持 4 层优先级降级（显式指定 > 渠道绑定 > 渠道默认 > 全局默认）
- **统一通道接入**：飞书、企微、WebSocket 等外部渠道通过标准 `AiChannelMessage` 接入，一次开发适配所有渠道
- **会话与压缩**：进程内会话记忆管理，超长对话自动摘要压缩，解决大模型上下文窗口限制
- **标准协议支持**：MCP 接口（JSON-RPC 2.0）和 A2A 接口（Agent-to-Agent 通信），可被外部智能体发现和调用

## 适用角色

后端开发者、AI 平台架构师、系统集成工程师。

## 核心价值

业务模块集成只需 4 步：引入依赖 → 声明 AiSkill Bean →（可选）实现渠道配置解析器 → 完成。将 80% 的 AI 基础设施工作标准化，业务团队只需关注自己的技能逻辑。多渠道接入不再重复开发，新渠道适配成本降低 90% 以上。
