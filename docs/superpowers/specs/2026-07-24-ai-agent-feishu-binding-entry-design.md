# 智能体管理页飞书渠道绑定入口设计

## 目标

将“飞书渠道绑定”从 AI 模块左侧独立菜单移动到智能体管理页面。在智能体列表顶部“新建智能体”按钮右侧增加“绑定飞书渠道”按钮，用户点击后进入现有飞书渠道绑定管理页面。

## 范围

本次只调整前端入口与导航关系：

- 从 `frontend/modules/ai/menus.js` 移除“飞书渠道绑定”菜单项。
- 保留 `/ai/feishu-bindings` 路由及现有 `AiFeishuBindingManage.vue` 页面。
- 在 `AiAgentManage.vue` 的智能体页顶部操作区增加“绑定飞书渠道”按钮。
- 按钮仅在“智能体”标签页显示，位置在“新建智能体”按钮右侧。
- 点击按钮通过 Vue Router 跳转到 `/ai/feishu-bindings`。
- 不调整飞书绑定新增、编辑、删除接口，不修改数据库结构、SQL、后端 Service 或 DAO。

## 交互设计

智能体页顶部操作区保持现有顺序：

1. 搜索框；
2. 新建智能体；
3. 绑定飞书渠道。

“绑定飞书渠道”使用普通按钮样式，与主操作“新建智能体”形成视觉层级。进入绑定页后继续使用现有列表、分页、新增、编辑和删除能力。

当智能体列表为空时，空状态区域仍只显示“新建智能体”；飞书绑定入口固定保留在页面顶部，避免出现两个重复入口。

## 路由与菜单

- 菜单中不再展示 `/ai/feishu-bindings`。
- 路由继续注册，保证按钮跳转、浏览器刷新和直接访问均可正常工作。
- 不新增重定向或嵌套路由。

## 错误处理

按钮只触发站内路由跳转，不发起绑定请求。若目标页面加载数据失败，继续由现有飞书绑定页面展示加载错误，不在智能体页重复处理。

## 测试

更新 AI 模块静态契约测试，验证：

- 菜单配置不再包含“飞书渠道绑定”。
- `/ai/feishu-bindings` 路由仍然存在。
- 智能体页面包含“绑定飞书渠道”按钮。
- 按钮仅在智能体标签页显示。
- 点击处理逻辑跳转到 `/ai/feishu-bindings`。
- 现有飞书绑定页面与 API 契约测试继续通过。

完成后运行：

```text
node --test frontend/modules/ai/tests/*.test.mjs
```

并在 `frontend/web-shell` 运行：

```text
npm run build
```

## 非目标

- 不将飞书绑定列表嵌入智能体管理页面。
- 不将飞书绑定改成抽屉或弹窗。
- 不删除现有飞书绑定页面或路由。
- 不修改后端接口、运行时消息路由或数据库。
