# AI 模型模板大模型下拉菜单设计

## 背景

模型配置管理的“模型模板”页当前将阿里云百炼模型按分类展开为大量按钮。模型数量增加后，页面占用空间较大，也不便于快速查找目标模型。

## 目标

- 将百炼模型按钮列表替换为统一的大模型下拉菜单。
- 下拉菜单支持搜索和清空。
- 下拉选项继续按现有模型类别分组。
- 选择模型后沿用现有新建配置流程。

## 交互设计

“阿里云百炼”模板卡片内展示一个 `el-select`：

- 使用 `filterable` 支持按模型名称或模型 ID 搜索。
- 使用 `clearable` 支持清空选择。
- 使用 `el-option-group` 按 `BAILIAN_MODEL_GROUPS` 分组。
- 每个 `el-option` 同时展示模型名称和模型 ID。
- 选中模型后调用现有 `openFromBailianModel(model)`，打开新建配置抽屉。
- 新建表单自动带入供应商、Endpoint、模型 ID、配置名称和描述。
- 打开抽屉后清空下拉值，关闭抽屉后可以再次选择同一模型。

“自定义”模板卡片和入口保持不变。

## 数据与边界

- 继续使用 `BAILIAN_MODEL_GROUPS` 作为唯一模型选项来源。
- 不增加后端接口。
- 不修改模型配置数据库结构。
- 不修改模型配置保存、编辑、导入、导出和连接测试行为。

## 测试

修改现有模型配置静态测试，验证：

- 模型模板页存在可搜索的模型下拉菜单。
- 下拉菜单使用 `el-option-group` 和 `BAILIAN_MODEL_GROUPS`。
- 选择事件能够找到模型并调用 `openFromBailianModel`。
- 模型模板页不再按模型循环渲染按钮。

运行全部 AI 前端静态测试，确保其他模型配置和管理页面契约不受影响。

## 验收标准

- 模型模板页的大模型通过分组下拉菜单展示。
- 可以搜索并选择任一现有百炼模型。
- 选择后正确打开并预填新建配置抽屉。
- 自定义模型入口保持正常。
- AI 前端相关测试全部通过。
